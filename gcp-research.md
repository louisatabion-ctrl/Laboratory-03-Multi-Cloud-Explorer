# Google Cloud Platform (GCP)

## Brief Overview
Google Cloud Platform (GCP), launched in 2008, is a suite of cloud services designed for modern applications. It specializes in data analytics, machine learning, and containerized workloads. GCP is widely used by research institutions and data-driven companies.

## Global Infrastructure
GCP operates in 35+ regions worldwide, each with multiple availability zones. Its infrastructure is built on Google’s private global fiber network, ensuring high performance and low latency.

## Cloud Management Console
![GCP Homepage Screenshot](screenshots/gcp-homepage.png)
The Google Cloud Console is a web-based interface for managing projects, resources, and billing.

## Core Services
- **Compute:** Compute Engine  
- **Storage:** Cloud Storage  
- **Networking:** VPC (Virtual Private Cloud)  
- **Identity:** Cloud IAM

## Advantages
1. Leadership in AI/ML and data analytics.  
2. Strong Kubernetes and container support.  
3. Cost-efficient pricing with sustained-use discounts.

## Enterprise Use Cases
- Running AI/ML research projects with TensorFlow.  
- Performing big data analytics with BigQuery.  
- Deploying containerized applications using Google Kubernetes Engine (GKE).
