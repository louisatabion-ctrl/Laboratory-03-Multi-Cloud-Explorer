# Laboratory 03 – Multi-Cloud Explorer

## Mission Overview
This laboratory explores the three leading public cloud platforms:  
- Amazon Web Services (AWS)  
- Microsoft Azure  
- Google Cloud Platform (GCP)  

The goal is to evaluate their core services, compare strengths, and recommend the most appropriate provider for different business scenarios.

## Mission Objectives
- Explore major public cloud platforms.  
- Identify core services offered by AWS, Azure, and GCP.  
- Compare cloud services across providers.  
- Analyze business requirements and recommend cloud solutions.  
- Create professional documentation using Markdown.  
- Continue developing a well-organized GitHub Cloud Computing Portfolio.

## Repository Structure

## Checkpoints
1. Expand Cloud Portfolio – Create folder and structure.  
2. Explore AWS, Azure, GCP – Research and document each platform.  
3. Compare Platforms – Build comparison table and answer reflection questions.  
4. Client Recommendations – Match scenarios to best cloud provider.  
5. Match Equivalent Services – Create reference table.  
6. Decision Matrix – Recommend platforms for business needs.  
7. Linux Investigation – Use KillerCoda to gather system info and map to cloud services.  
8. Mission Reflection – Write a 250–350 word reflection.
