# Client Recommendations

## Client A – Startup Company
**Recommended Platform:** AWS  
A startup launching a mobile application benefits from AWS because of its free tier and ability to scale quickly as demand grows. AWS offers cost-effective solutions that allow startups to experiment without heavy upfront investment. Its global infrastructure ensures the app can reach users worldwide as the company expands.  
**Services to Use:**  
- EC2 (Elastic Compute Cloud)  
- S3 (Simple Storage Service)  
- Lambda (Serverless Computing)

---

## Client B – University
**Recommended Platform:** Azure  
The university already uses Microsoft technologies such as Windows Server, Microsoft 365, and Active Directory, making Azure the most seamless choice. Azure provides tight integration with these existing tools, simplifying migration and management. It also offers strong security and compliance features suitable for educational institutions.  
**Services to Use:**  
- Azure Virtual Machines  
- Azure Active Directory  
- Azure Blob Storage

---

## Client C – AI Research Company
**Recommended Platform:** GCP  
An AI research company requires high-performance computing and advanced machine learning tools. GCP excels in AI/ML with TensorFlow integration, BigQuery for analytics, and Google Kubernetes Engine for scalable workloads. Its infrastructure is optimized for data-driven research and experimentation.  
**Services to Use:**  
- Compute Engine  
- BigQuery  
- Google Kubernetes Engine (GKE)

---

## Client D – Global E-Commerce Company
**Recommended Platform:** AWS  
A multinational e-commerce company needs highly available infrastructure with automatic scaling to serve customers worldwide. AWS offers the largest global reach, powerful scaling features, and mature e-commerce solutions. Its services ensure reliability, performance, and customer satisfaction across regions.  
**Services to Use:**  
- EC2 (Elastic Compute Cloud)  
- S3 (Simple Storage Service)  
- Auto Scaling
